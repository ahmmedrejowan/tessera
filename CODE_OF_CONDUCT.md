# How we treat each other

Tessera is a small project. The rule is simple: be kind, and assume the other person is trying.

- Talk about the work, not the person.
- Take a question at face value. Everyone was new once, including me.
- Disagree plainly and without heat. "This loses files when the disk is full" is useful;
  "this is rubbish" is not.
- No harassment, no slurs, no personal attacks, no unwanted attention, in issues, pull requests or
  anywhere else this project is discussed.

If someone is making the project a worse place to be, tell me: **hello@rejowan.com**. I read it
myself. I will listen, keep it to myself, and do something about it: a word, an edit, or being
asked to leave, depending on what happened.

That is the whole code of conduct. It is short because it is meant to be read.
