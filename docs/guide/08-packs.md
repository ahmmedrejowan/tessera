# A pack's page

Everything Tessera knows about one download, in one place. Open a pack from Browse, from search, or
from an asset's details.

## The head of the page

The cover, the name, how many files and assets it holds, its size, its license, its creator and
whether it is in a game or a collection yet. The buttons beside it:

- **Link to a game** copies the whole pack into a project you have linked.
- **Add to collection**.
- **Add files**, to grow the pack with a later download.
- **Edit details**, to correct anything by hand.
- **Archive**, to take it out of search without deleting it.
- **Delete**, which moves it to the bin.

## The tabs

- **Assets**: every model, sprite, sound and font the pack holds, as tiles. Search inside the pack,
  or group by folder.
- **Files**: every file exactly as it is on disk, with archives opened out like folders and every
  size shown. This is the truth of what you downloaded.
- **License**: what it allows, the credit line to use, the license text itself, and the proof kept
  with the pack.
- **About**: the source page, the creator, the version, the description, tags, genre and style, and
  when it was added.

## Editing details

**Edit details** opens the record: name, license, source and creator, version, description, tags,
genre, style, and the cover. **Read it again** asks Tessera to detect the license and source from
the pack's own files once more, which is useful after you have added files to it.

## Licenses for part of a pack

Some bundles ship a folder under different terms. A pack can carry a rule for a path, and every
file under that path is covered by it. The viewer always shows the license that applies to the
file in front of you, not just the pack's own.
