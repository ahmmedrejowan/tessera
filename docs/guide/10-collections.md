# Collections

A collection gathers packs and single files for one purpose: one game, one job, one mood.

## Making one

**Collections**, then **New collection**. Give it a name and a description. Add things from a
pack's page, from a selection in Browse, or from the viewer.

## Smart collections

Instead of adding things by hand, save a search. Anything that matches is in the collection, and
anything added later that matches joins it on its own. Browse has **Save as smart collection** for
exactly this: filter to what you want, then save it.

## Rules: what a collection will accept

A collection can carry rules, and anything that does not fit is refused when you try to add it:

- **Licenses** it accepts.
- **Creators**.
- **Styles**.
- **Tags**.
- **Kinds of asset**.

This is how a collection for a commercial game refuses a pack that may not be sold, rather than
letting it in quietly.

## Using one

Open a collection to browse only what is in it, copy the whole of it into a game, or see what it
comes to in files and megabytes.
