# Keyboard shortcuts

`⌘` on macOS, `Ctrl` on Windows and Linux.

## Anywhere

| What | Keys |
|------|------|
| Search, or go to a page or action | `⌘F` |
| Go to Home … Downloads | `⌘1` – `⌘6` |
| Back, forward | `⌘[` and `⌘]` (macOS), `Alt+←` and `Alt+→` |
| Add downloads | `⌘O` |
| Add a folder of packs | `⌘⇧O` |
| Settings | `⌘,` |
| Keyboard shortcuts | `⌘/` |

## The search box

| What | Keys |
|------|------|
| Move through the suggestions | `↑` `↓` |
| Run the suggestion, or search everything | `Enter` |
| Close the suggestions | `Esc` |

## Browse

| What | Keys |
|------|------|
| Move between assets | `←` `→` `↑` `↓` |
| Open what the cursor is on | `Space` or `Enter` |
| Pick a tile out | hold, or right-click |
| Pick more, or a range | `⌘`+click, `Shift`+click |
| Star what is picked | `S` |
| Pick everything the search matches | `⌘A` |
| Put everything back | `Esc` |

## The viewer

| What | Keys |
|------|------|
| Previous, next asset | `←` `→` |
| Fit to the window, actual size | `F`, `1` |
| Show or hide the details | `I` |
| Close | `Space` or `Esc` |

## The window

| What | Keys |
|------|------|
| Zoom in, out, reset | `⌘+`, `⌘−`, `⌘0` |
| Full screen | `⌃⌘F` (macOS), `F11` |
