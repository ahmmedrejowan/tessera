# Downloads

Paste a link, or a whole list of them, and Tessera fetches the file and adds it like any other
pack, with the link on record.

## What you can paste

- **An asset page** on a site Tessera knows: Kenney, Poly Haven, ambientCG, OpenGameArt, GitHub
  releases, Google Drive and Dropbox. Tessera finds the file behind the page.
- **A direct link** to a zip or an archive anywhere else.
- **A list**: one link per line, or a file holding them. Drop the file onto the page.

## While they run

The Downloads page shows each one with its size, its speed and how long is left. You can pause,
resume, retry a failed one or cancel it. Finished downloads are added to the library, and anything
whose license or source is unclear waits in Review.

## Settings

In Settings, under Downloads:

- **When a download finishes**: add it straight away, or keep it until you say so.
- **How many at once**, so a slow connection is not swamped.

## Site rules

Settings, under Sites, remembers what you decided about a site: the license its packs carry and
the creator to credit. Once a rule exists, the next pack from that site skips Review. Rules are
yours: edit or remove any of them.
